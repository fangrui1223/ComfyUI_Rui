# Third-Party Notices

## ComfyUI-xiaozhuguang

The following Rui features are source-level adaptations of selected modules
from `xiaozhuguang/ComfyUI-xiaozhuguang`, revision
`367b5610237890a10248e2cc3b8017a94aa439c9` (V11.3.0):

- universal slider
- selector
- node favorites and title annotations
- image comparison
- image loader
- theme manager, panel, presets, and styles

The adapted code is namespaced for Rui and includes the confirmed Rui-specific
filename, cache, queue, localization, boolean inversion, and group-control
behavior. The upstream project is licensed under the MIT License. The license
text is retained at `licenses/ComfyUI-xiaozhuguang-MIT.txt`.

`web/js/pinyin-pro.esm.js` is retained with the selected upstream favorites
module because it provides the same Chinese and pinyin search behavior.
