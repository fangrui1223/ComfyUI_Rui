# Rui 源码级等价迁移验收矩阵

## 1. 判定方式

- **E**：应与固定上游版本运行效果等价。
- **R**：已确认的 Rui 特有差异。
- **C**：当前 ComfyUI 版本所需兼容改动，必须记录原因。
- **A**：可自动化验证。
- **M**：需要真实前端手动或浏览器验证。

每项必须记录 `通过/失败/不适用`。标为不适用时必须写原因。

## 12. 允许差异登记

实施过程中出现上游与当前 ComfyUI API 不兼容时，在此表登记后才能接受：

| ID | 功能 | 上游行为 | Rui 行为 | 原因 | 证据 |
|---|---|---|---|---|---|
| C-001 | 图像加载器 | 上游不等待上传完成即可生成 prompt | Rui 在 `app.graphToPrompt` 前等待当前上传链完成 | 当前前端没有 `beforeQueuePrompt` 扩展钩子，所有运行入口最终都会调用 `graphToPrompt` | 本机前端源码与快速上传回归 |
